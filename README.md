# Workflow repair: text-layout demonstration

An original synthetic frontend demonstration by Direct Proof. Compare fragile
and responsive component layouts, resize them, inspect measured text clipping,
and compare supplied strings with rendered DOM text.

The parcel, appointment and review scenes are fictional. This is not a client
case study, translation service, booking system, shipping service or paid product.
Controls operate locally in the browser. No external API, form submission,
payment, account or customer data is used. GitHub provides the hosting service.

Open `index.html` locally or view the GitHub Pages site when enabled. Native-size
links open self-contained previews in a new tab. The demo requires JavaScript.

Validated in Chromium with 24 original fixture cases and 72 scene cases,
keyboard/pointer checks, live mismatch detection and touch emulation. This does
not certify translation quality, accessibility, physical devices, all browsers,
or arbitrary websites. DOM text preservation and visual readability are measured
separately. Short copy can fit even the fragile layout at wider sizes.

This repository contains only the standalone demonstration. It contains no
private product repository history or unrelated product engine. No additional
software license is included.
